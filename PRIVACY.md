# Privacy Policy — Rakazo Sheets

Last updated: 2026-11-06

Rakazo Sheets is a personal OAuth app used only by its owner, on the owner's own
infrastructure, to access the owner's own Google account data (Google Sheets and
Google Calendar).

## Data accessed
Spreadsheet and calendar data of the owner's Google account, only when the owner
asks the automation to read or change it.

## Use and storage
The data is used only to perform the requested action. It is not sold, shared with
third parties, or used for advertising. The OAuth refresh token is stored in the
owner's private secret manager. No data is collected from any other person.

## Retention and deletion
The owner can revoke access at any time at https://myaccount.google.com/permissions
and delete the stored token.

## Google API Services User Data Policy
Use of information received from Google APIs adheres to the Google API Services
User Data Policy, including the Limited Use requirements.
